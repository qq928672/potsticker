# 訂單串接 Google Sheets

網站結帳 → Google Apps Script（網頁應用程式）→ 「炙餃座 訂單管理」試算表。

## 試算表分頁

| 分頁 | 用途 |
|---|---|
| 訂單 | 一筆訂單一列。狀態欄有下拉選單（新訂單／製作中／可取餐／已完成／已取消），由店家手動更新 |
| 明細 | 每筆訂單的品項、單價、數量 |
| 商品 | 商品編號、單價、是否冷凍、是否上架。**下單金額以這一頁的單價為準** |
| 門市 | 可選的取餐門市，「開放取餐」取消勾選就不能選 |
| 設定 | 宅配運費、免運門檻、通知信箱、防濫用上限（淡黃底藍字可自行修改） |
| 總覽 | 訂單數、今日訂單、營收等，全部是公式 |

## 部署步驟（只需做一次）

1. 開啟試算表 → 擴充功能 → Apps Script。
2. 把 `gas/Code.gs` 全部貼進去，存檔。
3. 部署 → 新增部署作業 → 類型「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 第一次部署會要求授權（讀寫這份試算表、寄通知信），照畫面同意。
5. 複製「網頁應用程式網址」（結尾是 `/exec`），貼到 `index.html` 的 `ORDER_ENDPOINT`，提交並部署網站。
6. 要收新訂單通知信，在「設定」分頁填入「通知信箱」。

之後修改 `Code.gs` 要重新「管理部署作業 → 編輯 → 新版本」，網址才會用新程式。

## 資料與安全

- 網站送來的金額不採信：GAS 只看商品編號與數量，用「商品」分頁的單價、「設定」分頁的運費重新計算。
- 檢查項目：姓名、電話格式、取餐方式與門市、冷凍／現做商品規則、數量上下限、商品是否上架。
- 同一份訂單用 `clientId` 去重，網路重試或連點不會產生兩筆。
- 同一支電話 10 分鐘內有筆數上限；表單有隱藏欄位擋簡單機器人。
- 使用者輸入以 `=`、`+`、`-`、`@` 開頭時會加上單引號，避免被試算表當公式執行。
- 網頁應用程式網址是公開的，任何人都能對它送資料，所以上面的檢查都在伺服器端做。
- 網站上的 `ORDER_ENDPOINT` 留空時，結帳維持示範模式，不會送出任何資料。

## 商品或價格變動

網站的 `PRODUCTS`（index.html）與「商品」分頁要一起改。兩邊單價不同時，訂單以試算表為準，網站畫面顯示的金額會和回傳結果不一致。
